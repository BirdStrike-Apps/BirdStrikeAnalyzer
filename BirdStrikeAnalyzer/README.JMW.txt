Implemented Features:
    For this lab, I used OpenAI's ChatGPT Codex to generate the 
AnalyzerPage.cs file. This page closely resembles the concept
created in Figma for our client-sided app's analysis features.
It has minimal functionality regarding table column editing and 
sorting, and it allows confirmation of bird strikes in the To-Do
list.

How I Supervised AI:
    I allowed GPT to generate the files for this project. After It
finished generating them, I would either copy them into the project
destination (if they were additions to the program) or run them from
their current location (if they were the foundation of the app).
    In either scenario, I would test the functionality of every present
feature to ensure that the AI did not break anything that had previously
worked. If everything worked properly, I would make a commit and a pull
request. If something was wrong, I would delete or undo the changes and
prompt GPT again, providing more context, clearer instructions, or 
examples of the desired output in an attempt to generate what I wanted.
